SUFIYAN SIDDIQUI — INTERACTIVE PORTFOLIO STARTER

HOW TO RUN IN VS CODE
1. Extract the ZIP folder.
2. Open the folder in VS Code (File > Open Folder).
3. Open index.html.
4. Recommended: install the VS Code extension "Live Server".
5. Right-click index.html and choose "Open with Live Server".

FILES
- index.html: page structure and portfolio sections
- styles.css: manga storyboard design and responsive layout
- script.js: clickable panels, project detail popups and modal interactions
